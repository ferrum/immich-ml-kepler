# immich-ml-kepler

Machine Learning module for [Immich](https://github.com/immich-app/immich) compatible with old nVidia GPUs with the Kepler architecture, not officially supported by Immich

## Stack
`Genuine Immich installation --> **immich-ml-kepler** --> ONNX Runtime 1.6 --> cuDNN 8.0.3 --> CUDA 10.2 --> Hardware`
